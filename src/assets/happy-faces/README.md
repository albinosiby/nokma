# Happy Faces images

Upload JPG, JPEG, PNG, WebP, or AVIF files directly into this folder.
Use lowercase extensions and numbered names to control the slide order:
`01-family.jpg`, `02-friends.webp`, `03-celebration.jpg`.

The carousel discovers images automatically during the Vite build.
No image list or HTML changes are needed. Commit the images, then rebuild
and deploy the website. Uploading files to an already deployed server
does not update the built image list.

Descriptive filenames become the image alt text (without the numeric prefix).
The section stays hidden until at least one image is present.
